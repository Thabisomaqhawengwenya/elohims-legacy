# Elohim's Legacy — React Application

Production Vite + React + TypeScript strict mode application for Elohim's Legacy 3D Particle Store.

## Quick Start
```bash
npm install
npm run dev
```

* Dev Server: [http://localhost:5173/](http://localhost:5173/)
* Quality Gate: `npm run lint`
* Production Build: `npm run build`

For the full architectural and particle breakdown, refer to the root [README.md](../README.md).
